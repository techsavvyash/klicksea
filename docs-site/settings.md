# Settings

Click the menu-bar icon to show the companion, then click its gear.

## Voice

- **Speaking voice:** choose an installed macOS voice, or System default.
- **Speaking speed:** adjust from 0.5× to 2× of the default speech-rate setting.
- **Preview voice / Stop preview:** listen before choosing.
- **Start dictation after capture:** control automatic listening.
- **Speak answers aloud:** control native playback.

Preferences save automatically. Changes affect subsequent utterances; they do not change speech already in progress. Add voices in macOS Accessibility → Spoken Content (wording may vary by macOS version). If an installed voice is removed, the app falls back to the system voice.

## Agent

Choose Codex or Claude, optional model names, executable paths, and the Claude API key. Switching providers is disabled during active capture/provider work.

## Permissions

Settings links to Screen Recording, Microphone, and Speech privacy panes. You may need to relaunch after granting screen access.
