# Capture & voice

| Control | Action |
| --- | --- |
| Control–Shift–4 | Screenshot the display under the pointer and start dictation |
| Control–Shift–5 | Start or stop a screen clip, up to 30 seconds |
| Microphone | Start a question, or finish the current question manually |
| Capture icon | Screenshot; right-click for screen recording |
| Square Stop | Cancel an interaction, stop speech, or finish an active clip |
| Gear | Open Settings |

The bar is hidden on startup. Click the menu-bar icon to show it temporarily. Right-click the floating bar and choose **Hide companion** to dismiss it without ending the running task. Stop ends the interaction.

Dictation is on-device when the current language supports it. It stops after 55 seconds. The app sends after about 2.2 seconds without transcription changes; long pauses can finish a question. Speak naturally, or use the microphone button to finish manually.

Screenshots capture a whole display, not a selected rectangle. KlickSea's own windows are excluded. Clips are real MP4 recordings; the agent receives up to eight JPEG frames with timestamps, not the raw movie. Very brief events may be missed. No system audio is recorded for provider input.
